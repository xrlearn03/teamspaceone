# Downloads

Installer files and updater metadata served by the marketing site.

Build artifacts are **not** committed to this folder; they are generated and
staged here by the CI pipeline (`azure-pipelines.yml` > `PublishDownloads` stage)
and uploaded to the GCE web host.

- `Teamspace One.dmg` — macOS installer. Generated by the macOS Tauri build.
- `Teamspace-One-Setup.exe` — Windows installer. Generated by the Windows Tauri
  build.
- `update.json` — Tauri updater manifest. Generated by
  `apps/desktop/scripts/generate-update-manifest.mjs`.
