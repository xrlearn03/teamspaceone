# Downloads

Installer files and updater metadata served by the marketing site.

- `Teamspace One.dmg` — macOS installer (Apple Silicon build). ✅ Present.
- `Teamspace-One-Setup.exe` — Windows installer. ⚠️ **MISSING** — build the
  Tauri Windows bundle on a Windows machine or CI and drop the `.exe` here.

- `update.json` — Tauri updater manifest. Generated by
  `apps/desktop/scripts/generate-update-manifest.mjs` and consumed by the desktop
  app at `https://teamspaceone.in/downloads/update.json`.
